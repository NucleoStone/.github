
# NucleoStone

**Memoria · Asistencia · Autonomía**

Ecosistema experimental de proyectos independientes de inteligencia artificial.

## Proyectos

### SW — [StoneWave](https://github.com/Big-nenu/StoneWave)
Motor de memoria semántica para agentes.

### SB — [StoneBot](https://github.com/Big-nenu/StoneBot)
Agente asistente personal con herramientas y memoria.

### SV — StoneVision
Agente autónomo experimental orientado a la percepción, el aprendizaje y la iniciativa propia.

---

*Tres proyectos distintos. Un mismo núcleo.*
